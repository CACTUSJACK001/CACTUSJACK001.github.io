GILDED QUILL STUDIO — LUXURY CV WEBSITE

This version includes three upgraded fictional practice-client CV concepts:
1. Aurelia Executive — executive / quiet luxury
2. Noir Atelier — creative / editorial
3. Monument Modern — product / technology

Each portfolio card now shows a much more complete CV layout, with realistic sections, experience, skills, metrics and contact information. The View Full Layout button opens a detailed two-page presentation.

FILES
- index.html — website structure and portfolio content
- style.css — luxury dark theme and CV layouts
- script.js — interactive full-layout previews

PUBLISHING
Upload the folder contents to a GitHub repository and enable GitHub Pages from Settings > Pages > Deploy from a branch.

Before publishing, replace hello@gildedquill.studio in index.html with your real contact email if needed.
